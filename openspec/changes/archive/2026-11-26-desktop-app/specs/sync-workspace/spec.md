# Spec Delta

## Purpose

提供同步前的预演、执行与结果查看界面，让用户清楚知道「将要改哪些文件」，并在出错时能定位与恢复。

## ADDED Requirements

### Requirement: 队列展示

系统 SHALL 展示待执行队列，包含每个条目的技能名、方向（push / pull）、动作、目标路径与落地方式。

#### Scenario: 队列有内容

- **WHEN** 用户完成选边或有可同步项
- **THEN** 同步工作区列出条目及汇总计数

#### Scenario: 队列为空

- **WHEN** 没有任何待执行条目
- **THEN** 显示「暂无待同步项」空状态，执行按钮不可用

### Requirement: 执行前预演

系统 SHALL 在执行前展示预演清单，列出将创建、更新、跳过的条目数与逐条目标路径，并要求用户确认。

#### Scenario: 确认预演

- **WHEN** 用户点击执行
- **THEN** 先展示预演摘要与目标路径，用户确认后才开始写入

#### Scenario: 取消预演

- **WHEN** 用户在预演界面取消
- **THEN** 不产生任何文件写入，队列保持原状

### Requirement: 执行进度与结果

系统 SHALL 在执行过程中逐条展示进度，执行结束后展示 created / updated / skipped / failed 汇总与失败原因。

#### Scenario: 全部成功

- **WHEN** 计划中所有条目成功执行
- **THEN** 结果页显示成功计数，队列清空

#### Scenario: 部分失败

- **WHEN** 某些条目因 hash 不一致或权限失败
- **THEN** 结果页按失败与成功分组，逐条给出失败原因与路径

### Requirement: 恢复入口

系统 SHALL 在结果页提供备份位置与恢复方式：可打开备份目录，或复制对应的恢复命令。

#### Scenario: 查看备份

- **WHEN** 用户点击「查看备份」
- **THEN** 打开本次执行的备份目录，其中包含 manifest 与被备份文件

#### Scenario: 复制恢复命令

- **WHEN** 用户点击「复制恢复命令」
- **THEN** 剪贴板得到可直接执行的恢复命令，包含本次时间戳

### Requirement: 与 CLI 语义一致

系统 SHALL 使用与 CLI 相同的计划快照与执行语义，同一快照在界面与命令行执行的条目集合一致。

#### Scenario: 跨端一致性

- **WHEN** 同一份计划快照分别在界面与 CLI 中执行预演
- **THEN** 两端列出的条目数量、方向与目标路径一致

### Requirement: 执行后状态刷新

系统 SHALL 在执行完成后刷新索引与列表状态，已同步的冲突不再出现在冲突列表。

#### Scenario: 同步后查看列表

- **WHEN** 某冲突已按用户选择同步完成
- **THEN** 该技能不再标记为 drift，落地方式标记更新为当前形态
